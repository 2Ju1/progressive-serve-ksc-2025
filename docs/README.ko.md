# ProgressiveServe 한국어 요약

ProgressiveServe는 서버리스 환경에서 LLM 전체를 한 번에 불러오는 대신, 프루닝된 경량 모델로 먼저 응답하고 백그라운드에서 나머지 레이어를 복구하는 3단계 로딩 파이프라인입니다.

[논문 PDF](../paper/progressive-serve-ksc-2025.pdf) | [실험 결과](../results/README.md) | [English README](../README.md)

## 해결하려는 문제

서버리스 LLM은 요청이 없을 때 GPU 비용을 줄일 수 있지만, 새 인스턴스가 모델 파라미터를 원격 저장소에서 가져와 메모리에 적재하는 동안 첫 응답이 크게 늦어집니다. ProgressiveServe는 전체 모델 복구가 끝나기 전에 첫 응답을 제공해 사용자가 체감하는 지연을 줄입니다.

## 핵심 구조

- **단계 1:** Llama 2 7B의 32개 레이어 중 그룹 A(1-20, 29-32)와 A LoRA 어댑터를 우선 로드해 응답을 시작합니다.
- **단계 2:** 그룹 B(21-24)를 복구하고 AB LoRA 어댑터로 전환합니다.
- **단계 3:** 그룹 C(25-28)를 복구하고 어댑터를 비활성화해 원본 모델 구조를 완성합니다.
- 아직 로드하지 않은 레이어 위치에는 PassLayer를 두어 서비스 중단 없이 구조를 바꿉니다.

## 논문에 보고된 결과

NVIDIA RTX 5090과 Llama 2 7B를 사용한 실험에서 첫 토큰 응답 시간은 ServerlessLLM의 114초에서 90초로 줄었습니다. 이는 21.1% 감소입니다. 3단계 복구가 끝난 뒤에는 EM 55.67%, F1 66.11%로 기준 모델과 같은 성능을 기록했습니다.

세부 수치는 [`results/paper-results.csv`](../results/paper-results.csv)에 정리했습니다.
